# Тест-кейс: создание раздела продуктов

**ID:** TC_SECTION_001

**Цель:** Проверить возможность создания нового направления на странице «Продукты», аналогичного разделу «Системы электронного документооборота (СЭД)», и корректность его отображения на сайте.

**Предусловия:**
1. Пользователь авторизован в административной панели.
2. Пользователь имеет права на создание и редактирование разделов.
3. Доступен раздел `[01] Продукция`.

**Тестовые данные:**



- Название: `Тестовое направление продуктов`
- Символьный код: `testovoe-napravlenie`
- Родительский раздел: `Верхний уровень`
- Активность: включена
- Изображение: `test-products.jpg`
- Описание: `Подробное описание тестового направления продуктов`
- Краткое описание раздела: `Краткий анонс тестового направления`
- Сортировка: `100`
- Детальная картинка: не заполняется

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть страницу «Продукты» (`/product/`) | Отображается список существующих направлений продуктов |
| 2 | Включить «Режим правки» в верхней панели | Отображаются инструменты управления содержимым страницы |
| 3 | Над списком продуктов нажать «Добавить раздел» | Открывается форма создания раздела в инфоблоке `[01] Продукция` |
| 4 | На вкладке «Раздел» установить флажок «Раздел активен» | Флажок установлен |
| 5 | В поле «Родительский раздел» выбрать `Верхний уровень` | В качестве родительского раздела выбран верхний уровень |
| 6 | В поле «Название» ввести `Тестовое направление продуктов` | Название отображается в поле |
| 7 | Проверить автоматически сформированный символьный код. Если он не сформирован, ввести `testovoe-napravlenie` | Символьный код заполнен латинскими буквами, без пробелов |
| 8 | В поле «Изображение» загрузить файл `test-products.jpg` | Изображение успешно загружено и отображается в форме |
| 9 | В поле «Описание» выбрать «Визуальный редактор» и ввести `Подробное описание тестового направления продуктов` | Текст отображается в визуальном редакторе |
| 10 | Открыть вкладку «Доп. поля». В поле «Краткое описание раздела» ввести `Краткий анонс тестового направления` | Краткое описание отображается в поле |
| 11 | Открыть вкладку «Дополнительно». В поле «Сортировка» установить значение `100` | Значение отображается в поле сортировки |
| 12 | Оставить поле «Детальная картинка» пустым (если оно предусмотрено формой) | Дополнительное изображение не загружено |
| 13 | Нажать кнопку «Сохранить» | Раздел успешно сохранён, форма закрывается или отображается сообщение об успешном сохранении |
| 14 | Обновить страницу `/product/` | На странице появляется новый блок с названием, загруженным изображением и кратким описанием |
| 15 | Нажать на название нового раздела | Открывается страница `/product/testovoe-napravlenie/` с правильным заголовком и подробным описанием |
| 16 | Проверить содержимое нового раздела | Отображаются только продукты, относящиеся к данному разделу. При отсутствии продуктов страница открывается без ошибок |
| 17 | Вернуться на `/product/`, навести курсор на новый блок и нажать «Изменить раздел» | Открывается форма редактирования с ранее сохранёнными данными |

**Дополнительная проверка через административную панель:**

Открыть `Контент -> Контент (GS)-> [01] Продукция -> Разделы`.

**Ожидаемый результат:** созданный раздел присутствует в списке разделов верхнего уровня. Сохранённые данные соответствуют введённым значениям.

**Постусловия:**
1. Тестовый раздел создан и активен.
2. После завершения проверки отключить активность тестового раздела, чтобы он не отображался посетителям сайта.

**Результат тестирования:** Пройдено / Не пройдено / Заблокировано.

При обнаружении ошибки указать номер шага, фактический результат, приложить скриншот и описать условия воспроизведения.
