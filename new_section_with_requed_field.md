Цель: проверить, что раздел сохраняется без заполнения необязательных полей.

Предусловия:
- Пользователь авторизован и имеет права добавления разделов.
- Открыта страница «Продукты».
- Обязательность полей должна быть подтверждена настройками формы. Ниже предполагается, что обязательным является только название.
№	Действие	Ожидаемый результат
1	Включить «Режим правки»	Отображаются кнопки управления содержимым
2	Нажать «Добавить раздел» над списком продуктов	Открылась форма создания раздела в «[01] Продукция»
3	В поле «Название» — Обязательное поле — ввести Тестовый раздел продуктов	Название заполнено
4	Проверить, что в поле «Родительский раздел» выбран «Верхний уровень». Остальные настройки оставить по умолчанию	Раздел создаётся на одном уровне с СЭД
5	Не заполнять изображение, описание, краткое описание и остальные необязательные поля. Автоматически заполненные значения оставить без изменений	Вручную заполнено только название
6	Нажать «Сохранить»	Раздел сохраняется без ошибок о незаполненных необязательных полях
7	Открыть Контент → Контент (GS) → [01] Продукция → Разделы	В списке присутствует «Тестовый раздел продуктов»
8	Открыть созданный раздел через меню строки → «Изменить»	Название сохранено; необязательные поля, оставленные пустыми, не заполнены


После теста: отключить активность тестового раздела.

Результат: Пройдено / Не пройдено / Заблокировано.
