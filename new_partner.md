# Тест-кейс: добавление партнёра

**ID:** TC_PARTNER_001

**Цель:** Проверить создание партнёра, отображение его логотипа и описания в списке партнёров и на отдельной странице.

**Предусловия:**
1. Пользователь авторизован на сайте https://www.acrosoft.ru/ с правами на создание и редактирование элементов инфоблока `[01] Партнеры`.
2. Открыта страница https://www.acrosoft.ru/kompaniya/partnery/.
3. Партнёр с символьным кодом `testovyy-partner` отсутствует. 
4. Подготовлен файл `test-partner.png`


**Тестовые данные:**

| Поле | Значение | Примечание |
|---|---|---|
| Название | `Тестовый партнёр` | Обязательное поле |
| Символьный код | `testovyy-partner` | Фиксированное значение для проверки адреса страницы |
| Активность | Включена | Для отображения на сайте |
| Начало активности | Не заполняется | Без ограничения даты начала показа |
| Окончание активности | Не заполняется | Без ограничения даты окончания показа |
| Сортировка | `100` | Проверяемое значение |
| Картинка для анонса | `test-partner.png` | Логотип партнёра |
| Описание для анонса | `Тестовый партнёр — разработчик программного обеспечения для бизнеса.` | Тип содержимого — "Текст" |
| Детальная картинка | Не заполняется | Проверка использования логотипа из анонса |
| Детальное описание | `Тестовый партнёр разрабатывает программное обеспечение для автоматизации работы компаний. Компания "Акрософт" помогает подобрать решения партнёра и организовать их внедрение.` | Вводится через визуальный редактор |
| Вывести на главной странице | Выключено | Создание партнёра без его добавления на главную |
| Скрыть ссылки под партнёром (по одному адресу в строке) | Не заполняется | Исключения для облака ссылок не задаются |



## Шаги

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | На странице `/kompaniya/partnery/` включить "Режим правки" в верхней панели. Навести курсор на область списка партнёров | Появляется всплывающая панель управления |
| 2 | Нажать "Добавить элемент" на панели списка партнёров | Открывается окно добавления элемента инфоблока `[01] Партнеры` |
| 3 | На вкладке "Параметры" включить "Активность". Поля начала и окончания активности оставить пустыми | Активность включена, ограничения по датам не заданы |
| 4 | В поле "Название" ввести `Тестовый партнёр` | В поле отображается введённое название |
| 5 | В поле "Символьный код" установить `testovyy-partner`. Если включена автоматическая генерация, отключить связь с названием перед ручным изменением | В поле сохранено точное значение `testovyy-partner` |
| 6 | В поле "Сортировка" ввести `100` | В поле отображается `100` |
| 7 | Снять флажок "Вывести на главной странице". Поле "Скрыть ссылки под партнёром" оставить пустым | Флажок выключен, адреса исключений не заданы |
| 8 | Открыть вкладку "Анонс". В поле "Картинка для анонса" загрузить `test-partner.png` | В форме отображается загруженный логотип без ошибки загрузки |
| 9 | В поле "Описание для анонса" выбрать "Текст" и ввести анонс из тестовых данных | В поле отображается точный текст анонса |
| 10 | Открыть вкладку "Подробно". Детальную картинку оставить пустой | Дополнительное изображение не загружено |
| 11 | В поле детального описания выбрать "Визуальный редактор" и ввести два предложения из тестовых данных | Текст доступен для визуального редактирования и отображается без HTML-тегов |
| 12 | Нажать "Сохранить" | Элемент сохраняется без ошибки валидации. Окно добавления закрывается |
| 13 | Обновить `/kompaniya/partnery/` и найти `Тестовый партнёр` | В списке присутствует одна карточка нового партнёра. Отображается загруженный логотип без искажений и значка отсутствующего изображения |
| 14 | Нажать ссылку карточки нового партнёра | Открывается `/kompaniya/partnery/testovyy-partner/`. Страница не возвращает ошибку 404, заголовок — `Тестовый партнёр` |
| 15 | Проверить логотип и текст на странице партнёра | Используется логотип из анонса при пустой детальной картинке. Логотип расположен слева в верхней части содержимого. Отображается введённое подробное описание без обрезания текста и вывода HTML-тегов |
| 16 | Вернуться к списку партнёров, навести курсор на созданную карточку и нажать "Изменить элемент" | Открывается форма редактирования именно созданного партнёра |
| 17 | Проверить вкладки "Параметры", "Анонс" и "Подробно" | Название, символьный код, сортировка, флажок главной страницы, логотип, анонс и подробное описание соответствуют тестовым данным. Детальная картинка отсутствует |
| 18 | Закрыть форму кнопкой "Отменить". Открыть административный раздел: `Контент → Контент (GS) → [01] Партнеры → Элементы`. Найти элемент по названию и открыть на редактирование | Элемент доступен в административном разделе. Его ID и сохранённые данные совпадают с карточкой, созданной через сайт |

## Отдельная проверка облака ссылок

Автоматическое облако ссылок проверяется отдельным тестом: для нового тестового партнёра на сайте может не быть упоминаний. Отсутствие облака в таком случае не считается ошибкой создания партнёра.

Для проверки облака нужны заранее подготовленная страница с упоминанием партнёра и известный адрес этой страницы. Проверяются появление ссылки в списке партнёров и внутри карточки, а затем её скрытие через поле "Скрыть ссылки под партнёром".

## Ожидаемый итог

Партнёр создан в инфоблоке `[01] Партнеры`, присутствует в списке партнёров и открывается по собственному адресу. Логотип и подробное описание отображаются корректно. Введённые данные сохраняются и доступны для редактирования через сайт и административный раздел.

## Очистка после теста

1. В форме созданного партнёра снять флажок "Активность" и сохранить изменения.
2. Обновить `/kompaniya/partnery/` в браузере без авторизации.
3. Проверить, что тестовый партнёр отсутствует в публичном списке.

**Постусловие:** тестовый элемент сохранён в инфоблоке, но неактивен и не отображается посетителям в списке партнёров.
